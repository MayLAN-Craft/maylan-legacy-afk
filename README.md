# 🤖 MaylanAFK Plugin

**MaylanAFK** — это высокооптимизированный плагин для Bukkit/Spigot/Paper серверов, предназначенный для автоматического определения статуса игроков как "AFK" (Away From Keyboard). Плагин предоставляет гибкие настройки для отображения статуса в таб-листе, над ником (через scoreboard) и отлично интегрируется с PlaceholderAPI.

## ✨ Основные возможности

*   **Автоматическое определение AFK:** Отслеживает активность игрока через движения (`PlayerMoveEvent`), взаимодействие, чат (включая асинхронный), клики по инвентарю и т.д.
*   **Конфигурируемое время таймаута:** Настраиваемый интервал бездействия для объявления игрока AFK (по умолчанию 300 секунд).
*   **Визуальное отображение в Tab-листе:** Возможность добавить префикс (`[AFK]`) к имени игрока в списке.
*   **Scoreboard Префикс:** Использование `Team` Scoreboard для добавления префикса над именем игрока (эффективный метод).
*   **Бродкаст уведомлений:** Настраиваемые события при входе и выходе из статуса AFK.
*   **Поддержка PlaceholderAPI (PAPI):** Предоставляет множество готовых плейсхолдеров для использования в плагинах, таблицах лидеров и т.д.

## 🚀 Функционал API (Методы)

Плагин предоставляет следующие удобные методы для интеграции:

| Метод | Описание |
| :--- | :--- |
| `isAfk(UUID id)` | Возвращает `true`, если игрок в статусе AFK. |
| `getInactiveSeconds(UUID id)` | Сколько секунд игрок бездействовал (общее время). |
| `getAfkSeconds(UUID id)` | Как долго игрок находится в статусе AFK (с момента объявления). |

## ⚙️ Конфигурация (`config.yml`)

Вы можете настроить внешний вид и логику работы плагина, используя файл `config.yml`.

```yaml
afk-timeout-seconds: 300       # Время бездействия в секундах (По умолчанию: 5 минут)
check-interval-ticks: 100      # Как часто происходит проверка активности (100 ticks = 5 секунд при 20 TPS)

team-name: "AFK"               # Имя команды для Scoreboard
prefix-text: "[AFK] "          # Текст, который будет отображаться в качестве префикса

show:
  in-tab: true                 # Включить показ [AFK] в таб-листе (PlayerListName)
  above-name: true             # Включить префикс над ником через Scoreboard Team

broadcast:
  on-enter: true               # Объявлять, что игрок ушёл в AFK
  on-exit: true                # Объявлять, что игрок вернулся

placeholders:
  suffix: " &7[AFK]"   # Полный текст для TAB Suffix (с пробелом)
  tag: "&7[AFK]"       # Текст тега без пробела (для некоторых плагинов)
```

## 🛠️ Команды и Права

### Основная команда

| Команда | Описание | Требуемые права |
| :--- | :--- | :--- |
| `/afk` | Переключает статус AFK для игрока. Если вы в AFK, становитесь активным; если активны — уходите в AFK. | `maylanafk.afk` |

### Права (Permissions)

*   `maylanafk.afk`: Разрешает использование команды `/afk`.

## 💡 Использование PlaceholderAPI

Если установлен PlaceholderAPI, вы можете использовать следующие плейсхолдеры:

| Плейсхолдер | Пример использования | Описание |
| :--- | :--- | :--- |
| `%maylanafk_<player>_afk%` | `&7[AFK]` (если в AFK), `""` (иначе) | Статус AFK (`true`/`false`) |
| `%maylanafk_<player>_suffix%` | ` &7[AFK]` | Полный текст для TAB Suffix. |
| `%maylanafk_<player>_tag%` | `&7[AFK]` | Тег без пробела. |
| `%maylanafk_<player>_inactive_seconds%` | `305` | Общее количество секунд, что игрок неактивен. |
| `%maylanafk_<player>_afk_seconds%` | `12:45` (или просто число) | Сколько времени игрок находится в AFK. |
| `%maylanafk_<player>_inactive_mmss%` | `05:05` | Общее время бездействия в формате ММ:СС. |
| `%maylanafk_<player>_afk_mmss%` | `12:45` | Время в статусе AFK в формате ММ:СС. |

### Пример вызова PAPI (на сервере):

```
/papi parse %maylanafk_PlayerName_suffix%
```

## 📦 Требования и зависимости

*   **Сервер:** Spigot / Paper (Рекомендуется использовать Paper для лучшей производительности).
*   **Плагин:** PlaceholderAPI (Для полной функциональности плейсхолдеров).
